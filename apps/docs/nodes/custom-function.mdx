## Execution behavior

- Custom functions run only on the local desktop in a restricted runtime with no ambient filesystem, network, environment, credential, browser, or plugin access.
- A SHA-256 receipt binds successful verification to the exact function contract, source, and fixtures.
- This node has no declared output ports; its value is in controlling when or how later work proceeds.

## Common issues

- Imports, duplication, and material edits invalidate the verification receipt.
- Keep the contract narrow and use ordinary permissioned nodes for external side effects.


## Where it can run

- Desktop local runner

## Test and inspect

Use **Test node** in the editor to preview this step with the current configuration. A full run records resolved inputs, outputs, logs, duration, and any artifacts in the execution inspector.
